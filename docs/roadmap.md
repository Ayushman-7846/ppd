# Roadmap

| Milestone | Deliverables |
| --- | --- |
| Phase 1 | Attributed research overview, annotated four-task demo, interactive ambiguity tree, charted demo dashboard, protected workspace summary, authentication and database foundations, migrations and local setup |
| Phase 2 | Four analyzers, five provider adapters, credential-free curated execution, versioned data and prompts, immutable experiment manifests, durable execution, raw-response capture, retries, cancellation, and per-trial progress |
| Phase 3 | Versioned rubrics, task-specific checks and AI-assisted assessment, blind human reviews with adjudication, matched comparison and ranking, repeat consistency, and report exports |
| Phase 4 | Research Showcase, provider diagnostics, candidate benchmark, performance and security checks, migration-gated production configuration, and final documentation |

Phase 3 grades saved responses against versioned rubrics. Consistency, Analytics, and Reports use the stored evidence and experiment manifest. Further research can add larger independent datasets, calibrated reviewer studies, and mixed-effects analysis on suitable cohorts.
